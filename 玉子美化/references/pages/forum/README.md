# 论坛源码参考

这套参考页从“论坛表”的主题帖与楼层讨论结构中独立抽取，只依赖玉子美化 Runtime API v1。目录可以单独复制，不依赖其他参考页。

## 表格约定

- 表名：`论坛表`
- 建议字段：`分区/版面名`、`发帖账号名`、`账号标签`、`帖子标题`、`帖子正文`、`附加信息`、`热度/回应数据`、`时间文本`、`评论串`
- `附加信息`以中英文分号拆分标签，也识别逗号、顿号、竖线和 `#`。
- `评论串`以中英文分号拆条，以中英文冒号拆分评论者与正文。

## 视觉与交互

页面保留四色封面、版面胶囊、主帖正文、附加标签、作者信息、热度和楼层式评论。封面色由帖子标题稳定计算；评论的展开与收起只改变当前根节点内的临时状态。

## 文件职责

- `index.html`：静态工具栏和页面挂载点。
- `style.css`：以 `.yb-forum-page` 为唯一根作用域的论坛样式。
- `mount.js`：字段解析、安全 DOM 渲染、评论折叠、订阅和销毁。

本参考不含删除、写表、生成式能力、外部弹窗或宿主对象。本目录故意不提供 `project.json`，作者应自行把三个入口文件登记到项目清单。
