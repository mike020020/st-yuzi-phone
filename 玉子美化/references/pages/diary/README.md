# 小日记源码参考

这套参考页从“小日记表”的私人手帐展示思路中独立抽取，只依赖玉子美化 Runtime API v1。

## 表格约定

- 表名：`小日记表`
- 建议字段：`row_id`、`日期`、`角色`、`内容`
- `内容` 支持多行文本。
- `PS:` / `PPS:`（同时支持中文冒号）会进入附注区。
- 成对的 `~~文字~~` 会作为秘密标记显示；未闭合标记按普通文字处理。
- 页面最多展示前五条有效日记。

## 文件职责

- `index.html`：静态工具栏和挂载点。
- `style.css`：以 `.yb-diary-page` 为唯一根作用域的暖白手帐样式。
- `mount.js`：内容语法解析、安全 DOM 渲染、订阅和幂等销毁。

本参考不包含删除、写表、生成式能力、外部全局入口或宿主弹窗。顶部按钮仅调用 `context.actions`。

本目录故意不提供 `project.json`。请把三个入口文件登记到作者自己的项目清单。
