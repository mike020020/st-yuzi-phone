# 小日历源码参考

这套参考页从“小日历表”的月历展示思路中独立抽取，只依赖玉子美化 Runtime API v1。目录可以单独复制，不依赖其他参考页。

## 表格约定

- 表名：`小日历表`
- 建议字段：`日期`、`月份几天`、`星期几`、`节日`、`大事件`、`状态`、`天气`、`与今天的关系`、`内容`
- `日期` 支持 `YYYY-M-D`，也保留了“纪年-月份名-日数”形式的抽象日期解析。
- `与今天的关系` 支持：`3天前`、`前天`、`昨天`、`今天`、`明天`、`后天`、`3天后`。

## 文件职责

- `index.html`：静态工具栏和页面挂载点。
- `style.css`：以 `.yb-calendar-page` 为唯一根作用域的月历样式。
- `mount.js`：字段解析、月份网格、年份选择、日期选择、订阅和销毁。

## 保留与移除

保留月切换、年份选择、日期详情和七日关系推导。移除路由实现、表格写入、删除、生成式能力和任何外部全局入口。顶部按钮只调用 `context.actions`，月历交互只修改当前页面内的临时视图。

本目录故意不提供 `project.json`。作者应把三个入口文件登记到自己的项目清单，并按真实表头声明 target fields。
