# 直播源码参考

这套参考页从“直播表”的浅色剧场与弹幕墙思路中独立抽取，只依赖玉子美化 Runtime API v1。

## 表格约定

- 表名：`直播表`
- 建议字段：`直播间名`、`领衔阵容`、`阵容标签`、`直播标题`、`剧情舞台概述`、`对手戏看点`、`观看/互动数据`、`时间文本`、`剧情弹幕串`、`推角弹幕串`、`对线弹幕串`
- 三类弹幕均以中英文分号拆条，以中英文冒号拆分观众名与正文。
- `观看/互动数据` 同样按分号拆成状态胶囊。

## 本地交互

每个直播间可独立暂停或显示弹幕。这个状态只存在于当前页面，订阅刷新不会写回表格。

## 文件职责

- `index.html`：静态工具栏和挂载点。
- `style.css`：以 `.yb-live-page` 为唯一根作用域的直播舞台样式。
- `mount.js`：字段解析、稳定弹幕色调、渲染、交互和清理。

本参考不包含删除、写表、生成式能力或外部全局入口。输入框仅作为视觉元素，不发送数据。

本目录故意不提供 `project.json`，请在作者自己的项目清单中登记入口文件。
