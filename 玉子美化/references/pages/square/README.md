# 广场源码参考

这套参考页从“广场表”的东方暖玉动态流思路中独立抽取，只依赖玉子美化 Runtime API v1。

## 表格约定

- 表名：`广场表`
- 建议字段：`帖子ID`（也识别 `帖子唯一标识`）、`发帖账号名`、`账号标签`、`帖子标题`、`帖子正文`、`话题/附加信息`、`图片描述`、`视频描述`、`互动数据`、`时间文本`、`评论串`
- 评论串以中英文分号拆条，以中英文冒号拆分评论者与正文。
- 图片或视频描述为 `none` 时不显示入口。

## 本地交互

图片与视频入口打开当前根节点内的说明面板。面板只展示文本，不调用外部弹窗，也不会解析描述中的标记。

## 文件职责

- `index.html`：静态工具栏、内容挂载点和本地详情面板。
- `style.css`：以 `.yb-square-page` 为唯一根作用域的暖玉样式。
- `mount.js`：字段解析、安全 DOM 渲染、详情交互、订阅和销毁。

本参考不含删除、写表或生成式能力。本目录故意不提供 `project.json`。
