# 重要角色表

## sourceData.note

记录所有NPC（不包括主角）的档案与动态状态。

- 列说明
 * 角色类型：恋爱对象 / 家人 / 配角 等等
 * 一句话介绍：≤30字，仅客观事实，禁止性格标签
    √ 集团唯一继承人，国民顶流偶像
    × 温柔善良的国民偶像
 * 外貌特征：≤40字
 * 穿着打扮：≤40字，仅外在可见的服饰/饰品/妆容，禁止写气质气场
    √ 纯白真丝衬衫
    × 散发高贵气场
 * 基础属性："健康=数值；力量=数值；敏捷=数值；理智=数值；观察=数值；魅力=数值"，范围10-90
 * 特有属性："属性名=数值；"，可NULL，通常为角色的特殊技能或者其他
 * 在场状态：在场 / 离场
 * 人际关系：格式"角色名:关系标签"，多角色用分号分隔，同角色多标签用逗号
    √ 爱丽丝:同学; 木下:未婚妻关系
    × 和爱丽丝关系不好（缺角色名前缀）


## sourceData.initNode

为已登场角色各插入一条。

## sourceData.deleteNode

禁止。

## sourceData.updateNode

各项状态变化时更新。

## sourceData.insertNode

新角色登场时新增。

## sourceData.ddl

```sql
CREATE TABLE important_characters ( -- 重要角色表
  row_id INTEGER PRIMARY KEY, -- 行号
  name TEXT UNIQUE, -- 姓名
  role_type TEXT, -- 角色类型
  gender TEXT, -- 性别
  age TEXT, -- 年龄
  brief_intro TEXT, -- 一句话介绍
  appearance TEXT, -- 外貌特征
  outfit_text TEXT, -- 穿着打扮
  base_attributes TEXT, -- 基础属性
  special_attributes TEXT, -- 特有属性
  location_name TEXT, -- 所在地点
  presence_status TEXT, -- 在场状态
  relation_text TEXT  -- 人际关系
);
```
