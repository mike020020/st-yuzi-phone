# 选项表

## sourceData.note

记录每轮主角可以进行的动作选项。此表有且仅有一行。

- 列说明
 * 选项一 – 以第三人称去描述主角的行动，语言，偏向策略或推进剧情，猜测主角下一步可能会干什么，最合理的选择。
 * 选项二 – 以第三人称描述主角可采取的中立行动，不偏向任何立场。
 * 选项三 – 以第三人称描述主角可采取的善意行动，体现帮助、保护或安抚。
 * 选项四 - 以第三人称描述一下，根据当前剧情，去写一个有意思的和剧情不相干的身边突发事件，偏向可以带出新剧情，新互动方面的。例如主角一行人散步，就可以写有鬼屋活动（可以增加主角和其余人好感度的活动），从而可以让主角一行人带出新剧情。可以适当去看‘小日历表中当天的内容表’
 * 选项五 - 一段当前剧情的天气，风景，周边景色的具体描述，单纯的废话，用来代替‘继续’的


- 选项要求
 * 所有的选项不一定都是正面的，但都是根据当前user人设，char人设，最合理的推进剧情的方向，仅提供简练的客观动作或对话方向，不使用微表情、心理活动或环境描写，也不需要写出选项会造成的结果

## sourceData.initNode

游戏初始化时，生成五个初始选项。

## sourceData.deleteNode

禁止删除。

## sourceData.updateNode

每轮交互后必须更新此表，根据当前剧情生成新的五个选项覆盖原有内容。


## sourceData.insertNode

禁止操作。

## sourceData.ddl

```sql
CREATE TABLE options ( -- 选项表
  row_id INTEGER PRIMARY KEY, -- 行号
  option_1 TEXT, -- 选项一
  option_2 TEXT, -- 选项二
  option_3 TEXT, -- 选项三
  option_4 TEXT, -- 选项四
  option_5 TEXT -- 选项五
);
```
