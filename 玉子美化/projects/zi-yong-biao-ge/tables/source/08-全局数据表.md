# 全局数据表

## sourceData.note

记录当前时间、地点信息。此表有且仅有一行。

- 列定义
 * 当前时间 / 上轮场景时间：YYYY-MM-DD HH:MM
 * 经过的时间：{数值}{单位}，如"3小时20分""2天"
 * 当前位置：写具体空间，外出写地点名

- 时间规则
 * cur_time = prev_scene_time + elapsed_time
 * 初始化时prev_scene_time为NULL，cur_time直接填初始时间。
 * 每轮推进时：将上一轮cur_time写入prev_scene_time → 填写elapsed_time → 计算新cur_time。

## sourceData.initNode

故事初始化时插入唯一条目。

## sourceData.deleteNode

禁止。

## sourceData.updateNode

每轮推进时更新时间字段；地点状态变动时同步更新。

SQL示例：
UPDATE global_state SET prev_scene_time='2026-04-07 14:00', elapsed_time='2小时', cur_time='2026-04-07 16:00', current_location='别墅后巷' WHERE row_id=1;

## sourceData.insertNode

禁止。

## sourceData.ddl

```sql
CREATE TABLE global_state ( -- 全局状态表
  row_id INTEGER PRIMARY KEY, -- 行号
  cur_time TEXT, -- 当前时间
  prev_scene_time TEXT, -- 上轮场景时间
  elapsed_time TEXT, -- 经过的时间
  current_location TEXT -- 当前位置
);
```
