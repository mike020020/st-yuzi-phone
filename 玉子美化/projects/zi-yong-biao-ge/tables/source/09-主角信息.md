# 主角信息

## sourceData.note

记录主角核心信息。此表有且仅有一行。

- 列说明
 * 性别
 * 外貌特征：≤60字
 * 身份：≤40字，逗号分隔
 * 近况：一句话身体/情绪状态。正常时填"一切如常"，异常时写具体感受
    √ 左膝擦伤，有点烦躁
    √ 抑制剂快到时间了，后颈发热
 * 基础属性："健康=数值；力量=数值；敏捷=数值；理智=数值；观察=数值；魅力=数值"，范围10-90
 * 特有属性："属性名=数值；"格式，可NULL，通常为主角的特殊技能或者其他

## sourceData.initNode

故事初始化时插入主角条目。

## sourceData.deleteNode

禁止。

## sourceData.updateNode

字段变化时更新。

SQL示例: 
UPDATE protagonist_info SET current_condition='左膝擦伤，有点烦躁', base_attributes='健康=60；力量=78；敏捷=80；理智=44；观察=62；魅力=58' WHERE row_id=1;

## sourceData.insertNode

禁止。

## sourceData.ddl

```sql
CREATE TABLE protagonist_info ( -- 主角信息表
  row_id INTEGER PRIMARY KEY, -- 行号
  name TEXT NOT NULL, -- 姓名
  gender_desc TEXT NOT NULL, -- 性别
  age INTEGER NOT NULL, -- 年龄
  appearance TEXT NOT NULL, -- 外貌特征
  identity_text TEXT NOT NULL, -- 身份
  current_condition TEXT NOT NULL, -- 近况
  base_attributes TEXT NOT NULL, -- 基础属性
  special_attributes TEXT -- 特有属性
);
```
